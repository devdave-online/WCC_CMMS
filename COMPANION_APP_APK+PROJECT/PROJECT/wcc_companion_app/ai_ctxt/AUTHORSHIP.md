# Authorship (binding)

| Field | Value |
|-------|--------|
| **Sole author** | **Project owner** |
| Co-authors | **None** |
| Organizations / agencies credited as authors | **None** |
| AI systems credited as authors | **None** |

## Policy for agents and humans

1. The project owner is the only author of this companion app repository content.  
2. Do **not** add `@author`, “Created by”, “Co-authored-by”, or multi-party copyright headers that name anyone or any system other than the project owner.  
3. AI coding assistants may edit files under the project owner's direction; they are **not** authors and must not be listed as such.  
4. If historical notes mention tools (agents, IDEs), phrase them as *instruments*, not *authors*.  
5. When in doubt, attribute to the project owner only.

See also root `AUTHOR.md`.
